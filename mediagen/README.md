# وحدة توليد الوسائط (Media Generation Module)

وحدة متكاملة ومستقلة لتوليد وتحرير الصور، الفيديوهات، والصوتيات عبر الذكاء الاصطناعي لتطبيق Nexora.

## الميزات
- دعم مزودي التوليد المتعددين (OpenAI DALL-E, Google Imagen, Midjourney APIs).
- توليد الصور وتحويل النص إلى صورة وفيديو.
- إدارة الإعدادات والتحكم في الدقة ونسب الأبعاد.
