# Publish Release

يرجى الاعتماد علىgit logتوليد سجل التحديثات،ثم أنشئ جديدًاrelease

## سجل التحديثات

- عرض منذ آخر مرةrelease tagإلى الحاليcommitتعديل الـ
- لخص التغييرات وأنشئ سجل التغييرات, BUGإصلاح وUIادمج التعديلات قدر الإمكان،تأكد أن إجمالي عناصر سجل التحديث لا يتجاوز 10عنصر
- تجنب المصطلحات التقنية في السجل

استخدم التنسيق التالي:

```markdown
محتوى التحديث:

- xxx
- xxx

Updates:

- xxx
- xxx
```

(سجل التحديثات ثنائي اللغة)

بعد اكتمال إنشاء سجل التحديثات،اطلب من المستخدم تأكيد ما إذا كان سجل التغييرات منطقيًا،انتظر تأكيد المستخدم للنشر،إنشاءrelease

## نشر

استخدامgithub cliإنشاءrelease, ويرفق/يرفع app/release/xxx.apk ملف

- الرفع فقطarm64الإصدار, إعادة التسمية قبل الرفعapk،إضافة رقم الإصدار إلى اسم الملف
- releaseيستخدم العنوان رقم الإصدار, وصف استخدام سجل التحديثات
- tagاستخدام رقم الإصدار في الاسم،بدونv
