# Nexora 🤖💬

تطبيق محادثة ذكاء اصطناعي (LLM) أصيل لنظام أندرويد يدعم التبديل بين مختلف مزودي ومزودات الذكاء الاصطناعي بكل سلاسة.

---

## الميزات الرئيسية

- **تعدد المزودين**: يدعم نماذج متعددة (OpenAI, Claude, Google Gemini وغيرها).
- **واجهة مستخدم حديثة**: مصممة وفق أحدث معايير Material Design لنظام Android.
- **دعم كامل للغة العربية**: واجهة معربة بالكامل لتجربة استخدام سهلة وبسيطة.
- **أمان وخصوصية**: حفظ محلي للبيانات والمفاتيح على جهازك.
