# مسار توليد المحادثة (Chat Generation Pipeline)

يوثق هذا الدليل بنية مسار معالجة الرسائل وتوليد الردود في تطبيق Nexora.

## مراحل المعالجة
1. استقبال رسالة المستخدم ومعالجة المدخلات (Text, Images, Audio).
2. تطبيق أدوات MCP وسياق الذاكرة والمساعد المختار.
3. التوجيه إلى مزود الذكاء الاصطناعي المناسب عبر بث التدفق (SSE Streaming).
4. استلام الرد، معالجة كتل التفكير (Thinking Blocks)، وعرض النتيجة للمستخدم في الواجهة.
